Conclusión clave

En reposo el costo es ~$0. Ninguna automatización programada (Celery Beat, AUTO-01…37) llama a un LLM — solo consultan BD y envían emails. El gasto de API es 100% por uso: cada mensaje de chat a un agente y cada consulta a la base de conocimiento (RAG).

02 Diferencias a tener en cuenta

No es solo precio: cambiar de proveedor implica trabajo de código y riesgo de calidad.

Claude (Anthropic) — actual

  • Ya integrado en todo el backend (SDK + LangChain).
  • Calidad alta en razonamiento y seguimiento de instrucciones — ideal para el chat de agentes.
  • Prompt caching: hasta ~90% de ahorro en el prompt de sistema repetido.
  • Más caro por token (5–10× vs Gemini Flash).
  • Sin tier gratuito — todo es de pago desde el token 1.

Gemini (Google)

  • Mucho más barato y con tier gratuito en Flash.
  • Requiere reescribir código: los 3 nodos RAG usan el SDK directo de Anthropic.
  • Riesgo de calidad: los prompts pueden comportarse distinto — hay que re-testear.
  • SDK y formato de respuesta distintos (no es "pegar la key").
  • Modelos rotan/deprecan más rápido (ej. 2.0 Flash apagado).

05 Factores que cambian el costo

🗂️

Prompt caching (Claude)

Cachear el system prompt de los agentes baja el costo de entrada hasta ~90% en mensajes repetidos. Optimización opcional.

🆓

Tier gratuito (Gemini)

Modelos Flash tienen cuota gratis con límites de peticiones/min. Puede cubrir un club pequeño casi sin costo.

📦

Batch API (ambos)

−50% en tareas no urgentes (informes nocturnos). Aplica si mueves cargas asíncronas a lote.

🔤

Embeddings (OpenAI)

La ingesta RAG usa OPENAI_API_KEY, no Anthropic. Muy barato (centavos/miles de fragmentos). Presupuestar aparte.

📏

Tamaño del contexto

RAG con más fragmentos = más tokens de entrada. Limitar top-k del reranker controla el costo directamente.

🚦

Límite de gasto

Tope mensual en la consola del proveedor. Seguro contra sorpresas — no un gasto fijo.

06 Recomendación de decisión

Decisión tomada: mantener todo en Claude
  1. Ahora (lanzamiento): quedarse en Claude. Sin tocar código, sin riesgo de calidad. El volumen inicial de un club es bajo (~$12/mes).
  2. Poner límite de gasto en console.anthropic.com → Settings → Limits (ej. $30–50/mes) + alertas al 50/80%.
  3. Revisar a los 2–3 meses: si el uso crece al escenario Medio/Alto, evaluar el modo híbrido (RAG en Gemini Flash-Lite) — ahorra ~30% sin tocar el chat.
  4. Migrar todo a Gemini solo si el costo se vuelve un problema real y aceptas re-testear la calidad de los agentes.
  5. Quick win opcional: activar prompt caching del system prompt de agentes — reduce el costo de chat sin cambiar de proveedor.

Supuestos: chat ≈ 3.000 tok entrada + 400 salida; RAG ≈ check(~0,5k)+rerank(8×~0,6k)+generate(~3k+0,5k). Cifras redondeadas, sin prompt caching ni batch.
